# 社會統計滑卡

社會統計與社會研究法的練習卡，手機上像交友軟體一樣一張一張滑。可以加到主畫面，離線也能用。

畫面上方切換題庫，兩個題庫的題目、成績和自製卡各自分開：

| 題庫 | 題目來源 | 分組 |
|---|---|---|
| 社會統計 | 作者自己撰寫的講義與題庫 | 章節 |
| 社會研究法 | 國家考試研究方法選擇題（民國101年起）中社會學領域的量化與質性方法，社工專屬方法（單案設計、方案評估等）不收；答案為考選部公布的標準答案 | 量化／質性／通論，各再分主題 |

社會研究法題目多，每一輪最多出 30 張新卡，其餘是到期要複習的卡。

開啟：<https://si-kui-a.github.io/social-statistics-swipe-cards/>

## 怎麼用

| 步驟 | 做什麼 |
|---|---|
| 1 | 看題目，先在心裡或紙上答完 |
| 2 | 按「翻面：有把握」或「翻面：不確定」 |
| 3 | 看答案，往右滑＝答對、往左滑＝答錯 |

答錯的卡在這一輪最後再出現一次；答對的卡依 1、3、7、14、30 天的間隔再出現（萊特納盒）。頁面下方可以用自己的話加卡。

## 加到手機主畫面

| 手機 | 做法 |
|---|---|
| iPhone（Safari） | 分享按鈕 →「加入主畫面」 |
| Android（Chrome） | 右上選單 →「加到主畫面」或「安裝應用程式」 |

第一次要連網開啟一次，之後離線也能用；連網時會自動下載新題目。

## 資料

- 成績與自製卡只存在你的裝置，不會上傳。用「匯出成績」存成檔案備份，換手機時用「匯入成績」還原。
- 社會統計題目（`cards.json`）由作者自己撰寫的講義自動產生，不含課本原題。
- 社會研究法題目（`cards-research.json`）是國考原題，依著作權法第 9 條不受著作權保護。
- 匯出的成績檔標明是哪個題庫，只能匯入同一個題庫。
- 不使用任何外部服務或字型，沒有追蹤程式。
