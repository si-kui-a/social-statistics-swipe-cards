# 社會統計滑卡

社會統計與社會研究法的練習卡，手機上像交友軟體一樣一張一張滑。可以加到主畫面，離線也能用。

畫面上方切換題庫，兩個題庫的題目、成績和自製卡各自分開：

| 題庫 | 題目來源 | 分組 |
|---|---|---|
| 社會統計 | 作者自己撰寫的講義與題庫，加上國家考試中考統計本身的選擇題（依課程章節歸類，相關與迴歸另列「延伸」，不在期中、期末範圍） | 章節 |
| 社會研究法 | 國家考試研究方法選擇題（民國101年起）中社會學領域的量化與質性方法，社工專屬方法（單案設計、方案評估等）不收；答案為考選部公布的標準答案。另有自編的研究軟體操作題（SPSS、R、Excel／Google 試算表、質性編碼軟體），每題標明依據的軟體版本 | 量化／質性／通論／工具，各再分主題 |

社會統計另有「期中考（CH2–4）／期末考（CH5–10）」範圍可選。

開啟：<https://si-kui-a.github.io/social-statistics-swipe-cards/>

## 怎麼用

| 題型 | 作答 | 批改 |
|---|---|---|
| 選擇題 | 點選答案，再按「送出：有把握／不確定」 | 自動 |
| 計算題 | 輸入數字（可用小數、分數、百分比） | 自動，容許小數誤差 |
| 申論題 | 寫下答案（條列要點即可）後送出，勾選自己寫到的評分要點 | 寫到關鍵字的要點會先勾好，可自行修正；寫到六成要點算答對 |
| 問答卡 | 可在作答框寫下答案（選填），翻面後與答案對照，往右滑＝答對、往左滑＝答錯 | 自評 |

答錯的卡在這一輪最後再出現一次；答對的卡依 1、3、7、14、30 天的間隔再出現（萊特納盒）。送出時選的「有把握／不確定」只影響複習時間、不影響得分：不確定但答對的不升級、隔天再複習；有把握卻答錯的，本輪隔 3 張就再出現。

每張卡分基礎、標準、進階三級。App 依你在各章的答題表現，挑「大約七成五會答對」的新卡：剛開始多是基礎題，表現好就逐漸換成標準與進階題。每輪新卡數量也會調整：近期得分率高且待複習的卡不多就增加，答錯多或待複習的卡堆積就減少（每輪 5–40 張）。

申論題與問答卡寫的內容會存在手機裡，並隨「匯出成績」一起匯出，之後可以逐題細看。選擇題選了哪個選項、計算題輸入的數字也會記下來，匯出後可以分析答錯是出於哪一種誤解。

### 每輪怎麼出卡

設計參考 Anki（每日上限加上「自訂學習」可以跳出上限）與 Quizlet（未學／學習中／熟練三組）。

| 選項 | 做法 |
|---|---|
| 排程複習 | 到期的複習卡加上適量新卡；當天沒做完，切換章節再回來會接著做 |
| 全部刷完 | 所選範圍每張卡各出一次，一路滑到底；中途離開，下次接著做 |
| 單章／多章混合 | 單章：點一個章節只練那一章。多章混合：可選多個章節，「全部」就是範圍內所有章節的總數 |

畫面上方的「本輪 7/20」是這一輪已作答與總張數，只算第一次作答；「今天 32/60 張・首答 48%」是今天做過的不同卡片數／每日上限，以及今天第一次作答的答對率。答錯重做不另計，切換章節也不會變。

### 模擬考

選「模擬考」後選一份考卷。考卷依課綱設定範圍、大題、題數與時間，題目從題庫隨機抽：

| 題庫 | 考卷 | 依據 |
|---|---|---|
| 社會統計 | 期中（CH1–4，60 分）、期中小小考（20 分）、期末（CH5–6，60 分） | 課綱「概念理解、判斷、計算與解釋」；實際題型未公開，小小考後調整 |
| 社會研究法 | 期中（本學期範圍，90 分）、期末上機模擬（判讀與詮釋，60 分） | 期中為帶回家申論；期末參照臺灣社會學會社會調查師數據分析認證（上機寫研究紀要） |

作答中不顯示對錯；問答卡在交卷後自己批改，申論依關鍵字評分。時間到自動交卷，結束後顯示各大題得分、作答時間與分析。

### 什麼時候停下

都由程式判斷，不靠自己記得停：

| 情況 | App 的做法 |
|---|---|
| 這一輪每張卡都答過一次 | 這一輪結束，顯示得分與分析；答錯的卡不再自動接著出，由你選「繼續複習答錯的」或「再練一輪」 |
| 今天做到每日上限（預設 60 張，☰ 可改） | 先停下，可選「再做 20 張」或「今天到此為止」 |
| 最近 20 題答對不到一半 | 先停下看分析：答錯很多時，先弄懂錯在哪比多做有用 |

### 一輪的分析

延伸作業審查「先提問、再提示、最後才給答案」的做法到每種題型。程式依作答判斷錯在哪裡，每一項附一個先想的問題：

| 題型 | 判斷 |
|---|---|
| 計算題 | 從輸入的數字判斷：比例與百分比混用（差 100 倍）、正負號弄反、四捨五入太早（差 5% 以內），其他算公式或步驟錯 |
| 選擇題 | 選到課程倉庫標記過的常見誤解時，顯示誤解名稱與對策；有把握卻答錯的，標成「以為懂」 |
| 申論題、問答卡 | 要點沒寫到、自評答錯；問答卡請自己寫一句「因為……」 |

另外列出易錯的章節與題型（答錯兩張以上，錯誤比例高的在前），以及有把握卻答錯的卡。

一輪結束與中途暫停時，都會列出每個領域（章節或主題）的錯誤率，並據此安排下一輪：

| 項目 | 做法 |
|---|---|
| 這一輪 | 每個領域的作答數、錯幾題、錯誤率；作答不到 3 題的寫「樣本不足」，不算百分比 |
| 長期等級 | 比照 Khan Academy，看該領域最近 10 題：沒答過為未開始、答對不到七成為嘗試、七成以上為熟悉、全對為精熟 |
| 下一輪新卡 | 錯誤率高的領域分到較多新卡，並先出它的基礎題（比照 ALEKS 先補先備概念）；同一輪裡單一領域最多占新卡的一半，除非其他領域已經沒有新卡 |
| 出題順序 | 排程複習時，同一領域盡量不連續出現（交錯練習） |

右上「☰」選單裡有：最近幾輪的成績、各章熟練度、怎麼用、自己做卡、成績備份。

## 資料

- 成績與自製卡只存在你的裝置，不會上傳。用「匯出成績」存成檔案備份，換手機時用「匯入成績」還原。
- 社會統計題目（`cards.json`）由作者自己撰寫的講義自動產生，不含課本原題。
- 社會研究法題目（`cards-research.json`）是國考原題，依著作權法第 9 條不受著作權保護。
- 匯出的成績檔標明是哪個題庫，只能匯入同一個題庫。
- 不使用任何外部服務或字型，沒有追蹤程式。
