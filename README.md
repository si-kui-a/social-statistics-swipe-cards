# 社會統計滑卡

社會統計與社會研究法的練習卡，手機上像交友軟體一樣一張一張滑。可以加到主畫面，離線也能用。

畫面上方切換題庫，兩個題庫的題目、成績和自製卡各自分開：

| 題庫 | 題目來源 | 分組 |
|---|---|---|
| 社會統計 | 作者自己撰寫的講義與題庫，加上國家考試中考統計本身的選擇題（依課程章節歸類，相關與迴歸另列「延伸」，不在期中、期末範圍） | 章節 |
| 社會研究法 | 國家考試研究方法選擇題（民國101年起）中社會學領域的量化與質性方法，社工專屬方法（單案設計、方案評估等）不收；答案為考選部公布的標準答案 | 量化／質性／通論，各再分主題 |

社會統計另有「期中考（CH2–4）／期末考（CH5–10）」範圍可選。

開啟：<https://si-kui-a.github.io/social-statistics-swipe-cards/>

## 怎麼用

| 題型 | 作答 | 批改 |
|---|---|---|
| 選擇題 | 點選答案，再按「送出：有把握／不確定」 | 自動 |
| 計算題 | 輸入數字（可用小數、分數、百分比） | 自動，容許小數誤差 |
| 申論題 | 寫下答案（條列要點即可）後送出，勾選自己寫到的評分要點 | 寫到關鍵字的要點會先勾好，可自行修正；寫到六成要點算答對 |
| 問答卡 | 可在作答框寫下答案（選填），翻面後與答案對照，往右滑＝答對、往左滑＝答錯 | 自評 |

答錯的卡在這一輪最後再出現一次；答對的卡依 1、3、7、14、30 天的間隔再出現（萊特納盒）。送出時選的「有把握／不確定」只影響複習時間、不影響得分：不確定但答對的不升級、隔天再複習；有把握卻答錯的，本輪隔 3 張就再出現。

每張卡分基礎、標準、進階三級。App 依你在各章的答題表現，挑「大約七成五會答對」的新卡：剛開始多是基礎題，表現好就逐漸換成標準與進階題。每輪新卡數量也會調整：近期得分率高且待複習的卡不多就增加，答錯多或待複習的卡堆積就減少（每輪 5–40 張）。畫面上方會顯示本輪的複習與新卡數。

申論題與問答卡寫的內容會存在手機裡，並隨「匯出成績」一起匯出，之後可以逐題細看。頁面下方可以用自己的話加卡。

## 加到手機主畫面

| 手機 | 做法 |
|---|---|
| iPhone（Safari） | 分享按鈕 →「加入主畫面」 |
| Android（Chrome） | 右上選單 →「加到主畫面」或「安裝應用程式」 |

第一次要連網開啟一次，之後離線也能用；連網時會自動下載新題目。

## 資料

- 成績與自製卡只存在你的裝置，不會上傳。用「匯出成績」存成檔案備份，換手機時用「匯入成績」還原。
- 社會統計題目（`cards.json`）由作者自己撰寫的講義自動產生，不含課本原題。
- 社會研究法題目（`cards-research.json`）是國考原題，依著作權法第 9 條不受著作權保護。
- 匯出的成績檔標明是哪個題庫，只能匯入同一個題庫。
- 不使用任何外部服務或字型，沒有追蹤程式。
